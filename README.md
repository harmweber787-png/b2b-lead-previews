# NPPES Data Pack – preview page

This repository hosts the public preview page for a data pack built from the free, public CMS NPPES NPI Registry: 60 dental organizations in Texas, 20 mental-health organizations in California, and the Python script that builds such lists for any US state.

- Preview and purchase: https://harmweber787-png.github.io/b2b-lead-previews/
- Source of all records: https://npiregistry.cms.hhs.gov (retrieved on 26 October 2026)
- Names are the authorized officials listed in NPPES. Phone numbers are as listed in NPPES and have not been called or checked.
